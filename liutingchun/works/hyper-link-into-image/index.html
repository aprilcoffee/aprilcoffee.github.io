Hyper-Link into Image

把超連結轉換成圖片

Year
2016
Type
Internet Art
Materials
Router, Mobile, code with programming language Ruby

In the era of the Internet, we browse through pages and pages of content. Read the paragraph, click the next link, and repeat the same behavior. Massively and greedily ingest all the information without digesting and take it for granted. The webpage itself is an image, we read and browse all the information repeatedly.

I tried to block the familiar way people browse the internet by removing the most important component "Hyperlink". When surfing the internet through the browser, every webpage became a static image, which lost the ability to link to another webpage. By setting up a wi-fi router in the space and blocking all the wireless connection, audiences are forced to connect to the router I run, which had been written a script to redirect the request-URL into a static image. All the web pages they see will become an image screenshot from the webpage.

在網路世界中，我們瀏覽著一頁又一頁的頁面，閱讀著其中的資訊，並點選了下一個連結，重複又重複繼續著下一張頁面。大量且貪婪的攝取著資訊卻不經過消化，而成為習以為常的慣性行為卻不自知。網頁本身即是一張靜態影像，我們預期並瀏覽其上的資訊。不斷不斷重複。

我企圖阻斷觀眾習以為常的網頁瀏覽方式。嘗試將網路最重要的部分超連結(Hyperlink)移除，當透過瀏覽器瀏覽網頁時，得到的是一張固定靜態影像，因此也缺乏了連結至下一個頁面的能力。透過架設一台於展場的基地台，並且屏蔽場域中的無線網路，迫使現場觀眾在使用網路時必須要連結至預設的基地台。在基地台上撰寫將請求的網址(request-URL)轉換為靜態影像的腳本。讓現場觀眾所有網頁瀏覽過程都變成一張張靜態的圖片。
