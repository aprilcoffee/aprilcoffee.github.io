# Raw sources

The wiki is written from these sources. The LLM reads them but never edits them.

Already used:
- `../../data/site.json`: works (EN/DE/ZH), CV, performances, bio, statement
- `../../posts/*.md`: blog posts (Mandarin)

Drop new material here (one file per source, any of .md, .txt, .pdf), for example:
- interviews, press texts, exhibition texts, catalogue essays
- talk abstracts or transcripts, thesis summaries
- an `about-me.md` with things you want visitors to know (process, influences, FAQ answers)

Then ask for an **ingest** (see `../CLAUDE.md`).

`private/` is ignored by the wiki: notes there are never used in pages or by the chat.
Everything else in this repository is public.
