# Hyper-Link into Image (把超連結轉換成圖片)

An internet-art installation (2016). A Wi-Fi router in the space, running a Ruby script, turned every web page visitors opened into a static screenshot, removing the hyperlink and with it the habit of endless clicking.

## Facts

- **Year:** 2016
- **Type:** Internet Art
- **Type (de):** Netzkunst
- **Type (zh):** 網路藝術
- **Materials:** Router, Mobile, code with programming language Ruby
